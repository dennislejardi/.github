# Dennis Lejardi

I build products across civic technology, media automation, and games—from the first product decision through implementation, validation, and release.

Most of the implementation repositories are private. The public work here focuses on what I built, the decisions behind it, and the evidence that it works.

## Selected work

- **Pluribus** — a mobile civic product that connects representatives, legislation, elections, and official sources.
- **Atlas Cowork** — a provenance-aware media production system with explicit preproduction and release gates.
- **Army Survivors** — an eight-minute mobile action prototype where one operative grows into a squad.
- **Rivet's Junkyard Flight** — a compact physics game built around constrained controls and fast retries.
